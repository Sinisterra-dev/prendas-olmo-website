# Prendas Olmo Website

Responsive landing page for Prendas Olmo, a fashion store focused on women's and men's clothing. Built as a modern frontend prototype featuring responsive design, product showcase, company information, and contact sections.

## Project Structure

```
prendas-olmo-website/
│
├── assets/
│   ├── images/
│   ├── icons/
│   └── favicon.ico
│
├── css/
│   └── styles.css
│
├── js/
│   └── main.js
│
├── pages/
│   ├── nosotros.html
│   ├── mujer.html
│   ├── hombre.html
│   ├── colecciones.html
│   └── ofertas.html
│
├── index.html
├── README.md
└── .gitignore
```

## Technologies Used

- **HTML5** - Semantic markup
- **Tailwind CSS** - Utility-first CSS framework (via CDN)
- **JavaScript (Vanilla)** - Interactive functionality
- **Google Fonts** - Montserrat & Playfair Display
- **Material Symbols** - Google's icon font

## Features

- Responsive design for all screen sizes
- Smooth scroll animations
- Product showcase with hover effects
- Contact form
- Newsletter subscription
- Multi-page navigation

## Getting Started

1. Clone the repository
2. Open `index.html` in a web browser
3. No build process required - works directly in the browser

## Development

The project uses Tailwind CSS via CDN, so no build step is required. Simply open the HTML files in a browser to view the site.

## Customization

- **CSS**: Edit `css/styles.css` for custom styles
- **JavaScript**: Edit `js/main.js` for interactive functionality
- **Tailwind Config**: Each HTML file contains a Tailwind configuration script in the `<head>` section
